# NewAPI 账户余额监控

新增监控时选择 `NewAPI 余额`，填写站点 HTTPS 地址（可带 `/v1`）、对方个人设置生成的**个人访问令牌**，以及对方要求的用户 ID。用户 ID 有独立输入框，不需要操作高级请求头。个人令牌以现有 API Key 加密字段保存；它与模型 API Key 不同，切换检查方式时必须重新填写凭据。

程序仅查询 `GET /api/user/self` 的 `data.quota`，不以令牌额度接口作为账户余额回退。V1、V2 模式都支持此独立监控；系统总开关关闭时停止查询。返回原始 `quota` 单位，余额小于等于 0 标记降级，查询失败显示错误；本版本未提供美元换算、自定义预警阈值或消息推送。历史沿用现有配额快照。

余额请求不跟随重定向；只携带加密字段提供的访问令牌和可选 `New-Api-User`。生产部署不会自动填入第三方凭据，需管理员逐站配置。
