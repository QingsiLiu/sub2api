套餐路由调度与资金池扣减原理

每个订阅套餐对应一个独立的共享额度资金池。用户凭该订阅生成的 API Key 发起请求时，网关将校验所请求模型对应的分组是否被该套餐所包含。 如所包含的分组设定了结算倍率（如 Grok 0.85x 或 Claude 1.1x），系统将以 实际 Token 消耗 × 渠道基准单价 × 分组结算倍率 自动扣减月度与滑动窗口限额。
