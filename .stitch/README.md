# Stitch design source

The Stitch project is `projects/10497566828730451080`.

The current design system is **Sub2API · Clear Signal**. The generated screens in
`designs/` are the visual reference for the dashboard, subscriptions, API keys,
and admin subscription plans. They preserve the existing information
architecture while defining the typography, contrast, spacing, responsive
behavior, and shared-quota explanation used by the implementation.
